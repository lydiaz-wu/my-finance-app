# 我的財務小管家 v32

1. 將本 ZIP 解壓後整個目錄部署到私人 GitHub Pages（公開程式不含財務資料）。
2. 開啟網頁 →「設定」→ 匯入另外提供的 `my_finance_private_plan_v32.json`。
3. 每月到「本月」填入月底銀行現金、投資市值、其他資產及信用卡／其他負債；缺額填 0。
4. 「交易／信用卡」記錄資產移轉、信用卡消費、分期及還款。交易不直接修改已確認的月底帳戶餘額；每月底要重新對帳。
5. 「目標」可標記結婚／旅遊等用途預留。它不增加資產；指定支出時間供未來規劃參照。
6. 「設定」→ 匯出私人 JSON，每月備份並傳給 ChatGPT 規劃。

重要：瀏覽器資料存在 localStorage，清除資料可能遺失；請保管備份。所有金額和原訂目標留在私人 JSON，不要上傳到公開 GitHub。舊版 `plan.card` 屬既有現金流預算，與新增信用卡交易未自動去重，請避免將兩者當作額外支出重複加總。
