# 我的財務小管家 v27

## GitHub Pages
1. GitHub 建立新 repository，例如 `my-finance-app`
2. 把本資料夾內所有檔案上傳到 repository 根目錄
3. Settings → Pages
4. Build and deployment：Deploy from a branch
5. Branch：main；Folder：/ (root)；Save
6. 等 GitHub 顯示 Pages 網址後，用 Safari 開啟
7. iPhone：Safari 分享 → 加入主畫面
